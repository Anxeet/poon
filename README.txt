POONAM — A LITTLE PROPOSAL WEBSITE
==================================

FILES
- index.html       The page structure and all on-screen text.
- style.css        Colours, layout, typography and animations.
- script.js        Story navigation, particle effects and button interactions.
- assets/          The four photos you uploaded, copied into this project.

HOW TO RUN
1. Extract the ZIP file.
2. Keep the assets folder beside index.html (do not move the photos out of it).
3. Double-click index.html to open it in Chrome, Edge or Firefox.
4. For the best result, open it on a phone or desktop with a modern browser.

HOW TO PERSONALIZE
- Open index.html in VS Code.
- Search for "Poonam" to change her name.
- Edit the paragraphs in index.html and the four story lines in script.js.
- Replace any photo in assets/ with another image, keeping the same filename if you want
  the page to continue working without changing the HTML.
- The site currently uses no audio. You can add a song later if you have a specific track
  and want a click-to-play music control.

NOTES
- This is a static website; no server, account, or installation is required.
- Google Fonts are loaded online. The site still works offline with fallback fonts.
- The "I need a little time" choice is intentional and respectful; it lets her respond
  without pressure.

MUSIC
- Your uploaded "Jeene Laga Hoon" track is included as assets/jeene-laga-hoon.mp3.
- It starts when the visitor presses "Open your little surprise" (browser autoplay rules
  require a user gesture). The floating music button can pause or resume it.
- Keep the MP3 in the assets folder.
